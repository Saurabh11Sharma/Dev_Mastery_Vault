## How to study

For every topic, capture the mental model, mechanics, a runnable example, trade-offs, failure modes, tests and an interview explanation. Reading alone is not mastery: implement the concept, test it and explain why the design is appropriate.

## Suggested hands-on stack

TypeScript · Node.js LTS · NestJS · PostgreSQL · React / Next.js · Docker Compose · Jest or Vitest · GitHub Actions · AWS.

This is a learning library, not a collection of copied book chapters. Book references link to publishers or original resources; notes are written as study guidance.
